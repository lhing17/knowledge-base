# 赌神数学家

## 凯利公式
### 凯利公式的数学表达

> f* = p - q / b

其中p为胜率，q为失败率(1-p)，b为赔率

### 凯利公式的作用
凯利公式解决的只有一件事：在已知概率和赔率的前提下，将长期资金的对数增长率最大化。它追求的是长期复利最优，但不保证：
- 稳定收益
- 小回撤
- 心理舒适
事实上，使用凯利公式进行赌博或投资，资金长期处于之前的最高水平之下。

### 凯利公式只看当前总资产，不考虑钱的来历
凯利不区分：

- 老钱 / 新钱
- 早赚的 / 后赚的

每一刻你都应该把：

> 全部当前资产视为一个整体，重新按比例配置

把资金“分批单独算凯利”是常见但危险的错误

### 随着本金变大，早期结果一定会被“淹没”

这是数学必然，不是策略失败

投资结果由：

- 资产规模最大时期的几次决策决定

早期阶段的意义不在于赚了多少钱，而在于：

- 是否活下来
- 是否学会控制仓位
- 是否避免致命错误

### 分数凯利
凯利公式给出的实际上是仓位控制的极限水平，在实践中通常应该更保守，对你算出来的凯利仓位整体打折。常见的做法是对凯利仓位乘以一个1/2或1/4的系数。

### 凯利与价值投资（如巴菲特）的关系

凯利更像是：
- 风险与仓位管理的数学极限

巴菲特做的是：
- 极少数高胜率机会 + 极端耐心

本质一致之处：
- 都追求长期复利
- 都极度厌恶破产风险

实践差异：
- 巴菲特用“高确定性”降低凯利需求
- 普通投资者用“低仓位”对冲不确定性

### 一句话总结
凯利不是让你赚得更快的公式，而是让你在长期不确定性中，以尽量不自毁的方式活得更久。

### 投资的真谛在于避免犯错
找到不应该怎么做比找到应该怎么做要容易得多
