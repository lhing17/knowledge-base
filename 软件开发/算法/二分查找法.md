## 什么是二分查找法

二分查找法（Binary Search），也称为折半查找，是一种在有序数组中查找特定元素的搜索算法。它通过反复将搜索区间对半分割，将目标值与中间元素比较，从而快速缩小搜索范围。

### 简单理解
想象你在猜一个1到100之间的数字，每次猜测后会告诉你"太大了"或"太小了"。最聪明的策略是：
- 第一次猜50（中间值）
- 如果太大，下次在1-49中猜25
- 如果太小，下次在51-100中猜75

这就是二分查找的思想：**每次都选择中间位置，根据比较结果排除一半的可能性**。

## 二分查找法的核心思想

### 1. 分治策略
将大问题分解为小问题，通过解决小问题来解决大问题。

### 2. 减治思想
每次操作都能将问题规模减少一半，快速逼近答案。

### 3. 边界控制
通过维护左右边界，确保搜索范围的正确性。

### 4. 循环不变式
在整个搜索过程中，目标值（如果存在）始终在[left, right]区间内。

## 二分查找法的特征

### 1. 有序性要求
数组必须是有序的（升序或降序），这是二分查找的前提条件。

### 2. 随机访问
需要能够通过索引直接访问元素，因此适用于数组而不适用于链表。

### 3. 高效性
时间复杂度为O(log n)，比线性查找的O(n)要高效得多。

### 4. 空间效率
迭代版本的空间复杂度为O(1)，递归版本为O(log n)。

## 解题步骤

1. **确认前提条件**：确保数组是有序的
2. **初始化边界**：设置left和right指针
3. **计算中点**：mid = left + (right - left) // 2
4. **比较判断**：将target与arr[mid]比较
5. **更新边界**：根据比较结果更新left或right
6. **循环或递归**：重复步骤3-5直到找到目标或确定不存在

## 经典例题详解

### 例题1：基础二分查找

**问题描述**：在有序数组中查找目标值target，如果存在返回其索引，否则返回-1。

**分析过程**：
1. **初始化**：left = 0, right = len(nums) - 1
2. **循环条件**：left <= right
3. **中点计算**：mid = left + (right - left) // 2
4. **比较逻辑**：
   - 如果nums[mid] == target，返回mid
   - 如果nums[mid] < target，left = mid + 1
   - 如果nums[mid] > target，right = mid - 1

**代码实现**：
```python
def binary_search(nums, target):
    """
    基础二分查找
    时间复杂度：O(log n)
    空间复杂度：O(1)
    """
    left, right = 0, len(nums) - 1
    
    while left <= right:
        mid = left + (right - left) // 2  # 防止整数溢出
        
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return -1

# 递归版本
def binary_search_recursive(nums, target, left=0, right=None):
    if right is None:
        right = len(nums) - 1
    
    if left > right:
        return -1
    
    mid = left + (right - left) // 2
    
    if nums[mid] == target:
        return mid
    elif nums[mid] < target:
        return binary_search_recursive(nums, target, mid + 1, right)
    else:
        return binary_search_recursive(nums, target, left, mid - 1)
```

### 例题2：查找第一个等于目标值的位置

**问题描述**：在有序数组中查找第一个等于目标值的位置，如果不存在返回-1。

**分析过程**：
1. **目标**：找到最左边的target
2. **关键点**：即使找到target，也要继续向左搜索
3. **边界更新**：找到target时，right = mid - 1

**代码实现**：
```python
def find_first_position(nums, target):
    """
    查找第一个等于目标值的位置
    """
    left, right = 0, len(nums) - 1
    result = -1
    
    while left <= right:
        mid = left + (right - left) // 2
        
        if nums[mid] == target:
            result = mid  # 记录当前位置
            right = mid - 1  # 继续向左搜索
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    
    return result

# 另一种写法
def find_first_position_v2(nums, target):
    left, right = 0, len(nums)
    
    while left < right:
        mid = left + (right - left) // 2
        
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    
    return left if left < len(nums) and nums[left] == target else -1
```

### 例题3：查找最后一个等于目标值的位置

**问题描述**：在有序数组中查找最后一个等于目标值的位置，如果不存在返回-1。

**分析过程**：

2. **关键点**：即使找到target，也要继续向右搜索
3. **边界更新**：找到target时，left = mid + 1

**代码实现**：
```python
def find_last_position(nums, target):

            result = mid  # 记录当前位置
            left = mid + 1  # 继续向右搜索
        elif nums[mid] < target:
            left = mid + 1

            right = mid - 1
    
    return result
```

### 例题4：搜索旋转排序数组

**问题描述**：整数数组nums按升序排列，数组中的值互不相同。在传递给函数之前，nums在预先未知的某个下标k上进行了旋转。给你旋转后的数组nums和一个整数target，如果nums中存在这个目标值target，则返回它的下标，否则返回-1。

**分析过程**：
1. **关键观察**：旋转数组的一半总是有序的
2. **判断策略**：先判断哪一半是有序的，再判断target在哪一半
3. **边界更新**：根据target所在的半边更新搜索范围

**代码实现**：
```python
def search_rotated_array(nums, target):
    """
    搜索旋转排序数组
    """
    left, right = 0, len(nums) - 1
    
    while left <= right:
        mid = left + (right - left) // 2
        
        if nums[mid] == target:
            return mid
        
        # 判断左半部分是否有序
        if nums[left] <= nums[mid]:
            # 左半部分有序
            if nums[left] <= target < nums[mid]:
                right = mid - 1  # target在左半部分
            else:
                left = mid + 1   # target在右半部分
        else:
            # 右半部分有序
            if nums[mid] < target <= nums[right]:
                left = mid + 1   # target在右半部分
            else:
                right = mid - 1  # target在左半部分
    
    return -1
```

### 例题5：寻找峰值

**问题描述**：峰值元素是指其值严格大于左右相邻值的元素。给你一个整数数组nums，找到峰值元素并返回其索引。数组可能包含多个峰值，在这种情况下，返回任何一个峰值所在位置即可。

**分析过程**：
1. **关键观察**：如果nums[mid] < nums[mid+1]，那么右边一定存在峰值
2. **判断策略**：比较mid和mid+1的大小关系
3. **边界更新**：向有峰值的一边搜索

**代码实现**：
```python
def find_peak_element(nums):
    """
    寻找峰值
    """
    left, right = 0, len(nums) - 1
    
    while left < right:
        mid = left + (right - left) // 2
        
        if nums[mid] < nums[mid + 1]:
            # 右边存在峰值
            left = mid + 1
        else:
            # 左边存在峰值（包括mid本身）
            right = mid
    
    return left

# 示例
nums = [1, 2, 3, 1]
print(find_peak_element(nums))  # 输出: 2 (nums[2] = 3 是峰值)
```

## 常见题型总结

### 1. 基础查找类
- **特点**：在有序数组中查找特定值
- **例题**：基础二分查找、查找插入位置
- **模板**：标准的left <= right循环

### 2. 边界查找类
- **特点**：查找第一个或最后一个满足条件的位置
- **例题**：查找第一个/最后一个等于target的位置
- **模板**：找到目标后继续搜索

### 3. 旋转数组类
- **特点**：在旋转的有序数组中进行查找
- **例题**：搜索旋转排序数组、寻找旋转点
- **关键**：判断哪一半是有序的

### 4. 峰值查找类
- **特点**：寻找局部最大值或最小值
- **例题**：寻找峰值、寻找山脉数组的峰顶
- **策略**：根据斜率方向选择搜索方向

### 5. 答案查找类
- **特点**：在一个范围内搜索满足条件的答案
- **例题**：求平方根、搜索二维矩阵
- **思路**：将问题转化为在答案空间中的二分查找

## 优化技巧

### 1. 防止整数溢出
使用`mid = left + (right - left) // 2`而不是`mid = (left + right) // 2`。

```python
# 可能溢出的写法
mid = (left + right) // 2

# 安全的写法
mid = left + (right - left) // 2
```

### 2. 边界条件的选择
根据具体问题选择合适的边界条件：

```python
# 闭区间 [left, right]
while left <= right:
    # ...

# 左闭右开区间 [left, right)
while left < right:
    # ...
```

### 3. 循环不变式
确保在整个搜索过程中，目标值始终在搜索区间内：

```python
# 维护循环不变式：target在[left, right]中
def binary_search_invariant(nums, target):
    left, right = 0, len(nums) - 1
    
    # 循环不变式：如果target存在，则target在[left, right]中
    while left <= right:
        mid = left + (right - left) // 2
        
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1  # target在[mid+1, right]中
        else:
            right = mid - 1  # target在[left, mid-1]中
    
    return -1
```

### 4. 模板化编程
针对不同类型的二分查找问题，使用相应的模板：

```python
# 模板1：基础二分查找
def template1(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = left + (right - left) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

# 模板2：查找边界
def template2(nums, target):
    left, right = 0, len(nums)
    while left < right:
        mid = left + (right - left) // 2
        if nums[mid] < target:
            left = mid + 1
        else:
            right = mid
    return left
```

## 解题思路总结

1. **识别二分查找问题**：
   - 在有序数组中查找
   - 搜索空间可以被分割
   - 存在单调性

2. **分析问题特点**：
   - 确定搜索空间
   - 明确搜索目标
   - 选择合适的边界条件

3. **设计比较逻辑**：
   - 确定mid的计算方式
   - 设计比较和更新策略
   - 处理边界情况

4. **编码实现**：
   - 选择合适的模板
   - 注意整数溢出
   - 验证循环不变式

## 时间复杂度分析

二分查找的时间复杂度为**O(log n)**，这是因为：
- 每次操作都将搜索空间减半
- 最多需要log₂n次操作就能找到目标或确定不存在
- 这比线性查找的O(n)要高效得多
