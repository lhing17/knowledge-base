## 什么是动态规划

动态规划（Dynamic Programming，简称DP）是一种算法设计技术，用于解决具有重叠子问题和最优子结构性质的问题。它通过将复杂问题分解为更简单的子问题，并存储子问题的解来避免重复计算。

### 简单理解
想象你在爬楼梯，每次可以爬1级或2级台阶。如果要爬到第n级台阶，你可以：
- 从第(n-1)级台阶爬1级到达
- 从第(n-2)级台阶爬2级到达

这就是动态规划的思想：**大问题的解可以由小问题的解组合得到**。

## 动态规划的核心思想

### 1. 状态定义
定义一个状态来表示问题的某个阶段，通常用dp[i]表示。

### 2. 状态转移方程
找出状态之间的关系，即如何从已知状态推导出新状态。

### 3. 初始状态
确定最简单情况下的状态值。

### 4. 返回结果
根据题目要求返回相应的状态值。

## 动态规划的特征

### 1. 最优子结构
问题的最优解包含子问题的最优解。

### 2. 重叠子问题
在递归过程中，同样的子问题会被多次求解。

### 3. 无后效性
当前状态只依赖于之前的状态，不依赖于未来的状态。

## 解题步骤

1. **分析问题**：确定是否适合用动态规划
2. **定义状态**：明确dp数组的含义
3. **找状态转移方程**：分析状态之间的关系
4. **确定初始状态**：设置边界条件
5. **确定计算顺序**：保证计算当前状态时，依赖的状态已经计算出来
6. **返回结果**：根据题目要求返回答案

## 经典例题详解

### 例题1：斐波那契数列

**问题描述**：计算斐波那契数列的第n项，其中F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)。

**分析过程**：
1. **状态定义**：dp[i] 表示斐波那契数列第i项的值
2. **状态转移方程**：dp[i] = dp[i-1] + dp[i-2]
3. **初始状态**：dp[0] = 0, dp[1] = 1
4. **计算顺序**：从小到大计算

**代码实现**：
```python
def fibonacci(n):
    if n <= 1:
        return n
    
    # 创建dp数组
    dp = [0] * (n + 1)
    
    # 初始状态
    dp[0] = 0
    dp[1] = 1
    
    # 状态转移
    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    
    return dp[n]

# 空间优化版本
def fibonacci_optimized(n):
    if n <= 1:
        return n
    
    prev2 = 0  # dp[i-2]
    prev1 = 1  # dp[i-1]
    
    for i in range(2, n + 1):
        current = prev1 + prev2
        prev2 = prev1
        prev1 = current
    
    return prev1
```

### 例题2：爬楼梯问题

**问题描述**：假设你正在爬楼梯。需要n阶你才能到达楼顶。每次你可以爬1或2个台阶。你有多少种不同的方法可以爬到楼顶呢？

**分析过程**：
1. **状态定义**：dp[i] 表示爬到第i级台阶的方法数
2. **状态转移方程**：dp[i] = dp[i-1] + dp[i-2]
   - 可以从第(i-1)级台阶爬1级到达第i级
   - 可以从第(i-2)级台阶爬2级到达第i级
3. **初始状态**：dp[1] = 1, dp[2] = 2
4. **计算顺序**：从小到大

**代码实现**：
```python
def climbStairs(n):
    if n <= 2:
        return n
    
    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2
    
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    
    return dp[n]
```

### 例题3：最大子数组和（Kadane算法）

**问题描述**：给定一个整数数组nums，找到一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

**分析过程**：
1. **状态定义**：dp[i] 表示以第i个元素结尾的最大子数组和
2. **状态转移方程**：dp[i] = max(nums[i], dp[i-1] + nums[i])
   - 要么从当前元素重新开始
   - 要么在之前的基础上加上当前元素
3. **初始状态**：dp[0] = nums[0]
4. **返回结果**：max(dp)

**代码实现**：
```python
def maxSubArray(nums):
    n = len(nums)
    if n == 0:
        return 0
    
    dp = [0] * n
    dp[0] = nums[0]
    max_sum = dp[0]
    
    for i in range(1, n):
        dp[i] = max(nums[i], dp[i-1] + nums[i])
        max_sum = max(max_sum, dp[i])
    
    return max_sum

# 空间优化版本
def maxSubArray_optimized(nums):
    max_sum = current_sum = nums[0]
    
    for i in range(1, len(nums)):
        current_sum = max(nums[i], current_sum + nums[i])
        max_sum = max(max_sum, current_sum)
    
    return max_sum
```

### 例题4：0-1背包问题

**问题描述**：给定n个物品，第i个物品的重量是w[i]，价值是v[i]。现在有一个容量为W的背包，求能装入背包的物品的最大价值。

**分析过程**：
1. **状态定义**：dp[i][j] 表示前i个物品在容量为j的背包中能获得的最大价值
2. **状态转移方程**：
   ```
   dp[i][j] = max(dp[i-1][j], dp[i-1][j-w[i]] + v[i])  // 如果j >= w[i]
   dp[i][j] = dp[i-1][j]  // 如果j < w[i]
   ```
3. **初始状态**：dp[0][j] = 0（前0个物品价值为0）

**代码实现**：
```python
def knapsack_01(weights, values, capacity):
    n = len(weights)
    # dp[i][j] 表示前i个物品在容量为j时的最大价值
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]
    
    for i in range(1, n + 1):
        for j in range(capacity + 1):
            # 不选择第i个物品
            dp[i][j] = dp[i-1][j]
            
            # 如果能选择第i个物品
            if j >= weights[i-1]:
                dp[i][j] = max(dp[i][j], dp[i-1][j-weights[i-1]] + values[i-1])
    
    return dp[n][capacity]

# 空间优化版本（一维数组）
def knapsack_01_optimized(weights, values, capacity):
    dp = [0] * (capacity + 1)
    
    for i in range(len(weights)):
        # 从后往前遍历，避免重复使用
        for j in range(capacity, weights[i] - 1, -1):
            dp[j] = max(dp[j], dp[j - weights[i]] + values[i])
    
    return dp[capacity]
```

### 例题5：最长递增子序列

**问题描述**：给定一个无序的整数数组，找到其中最长递增子序列的长度。

**分析过程**：
1. **状态定义**：dp[i] 表示以第i个元素结尾的最长递增子序列长度
2. **状态转移方程**：dp[i] = max(dp[j] + 1) for all j < i and nums[j] < nums[i]
3. **初始状态**：dp[i] = 1（每个元素自身构成长度为1的序列）

**代码实现**：
```python
def lengthOfLIS(nums):
    if not nums:
        return 0
    
    n = len(nums)
    dp = [1] * n  # 每个元素自身构成长度为1的序列
    
    for i in range(1, n):
        for j in range(i):
            if nums[j] < nums[i]:
                dp[i] = max(dp[i], dp[j] + 1)
    
    return max(dp)

# 示例
nums = [10, 9, 2, 5, 3, 7, 101, 18]
print(lengthOfLIS(nums))  # 输出: 4 ([2,3,7,18])
```

## 常见题型总结

### 1. 线性DP
- **特点**：状态转移呈线性关系
- **例题**：斐波那契数列、爬楼梯、最大子数组和
- **状态转移**：dp[i] 通常依赖于 dp[i-1], dp[i-2] 等

### 2. 区间DP
- **特点**：在一个区间上进行动态规划
- **例题**：矩阵链乘法、回文子串
- **状态定义**：dp[i][j] 表示区间[i,j]的最优解

### 3. 背包DP
- **特点**：在有限容量下选择物品
- **例题**：0-1背包、完全背包、多重背包
- **状态定义**：dp[i][j] 表示前i个物品在容量j下的最优解

### 4. 树形DP
- **特点**：在树结构上进行动态规划
- **例题**：树的直径、打家劫舍III
- **状态定义**：通常以节点为状态

### 5. 状态机DP
- **特点**：有多种状态，状态间可以转换
- **例题**：买卖股票问题
- **状态定义**：dp[i][state] 表示第i天在某种状态下的最优解

## 优化技巧

### 1. 空间优化
当状态转移只依赖于前几个状态时，可以用滚动数组优化空间复杂度。

```python
# 原始版本：O(n)空间
dp = [0] * n
for i in range(1, n):
    dp[i] = dp[i-1] + dp[i-2]

# 优化版本：O(1)空间
prev2, prev1 = 0, 1
for i in range(2, n):
    current = prev1 + prev2
    prev2, prev1 = prev1, current
```

### 2. 记忆化搜索
将递归+记忆化的方式转换为动态规划。

```python
# 记忆化搜索版本
def fib_memo(n, memo={}):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fib_memo(n-1, memo) + fib_memo(n-2, memo)
    return memo[n]
```

### 3. 状态压缩
当状态可以用位运算表示时，使用状态压缩DP。

### 4. 单调队列/栈优化
在某些DP问题中，可以用单调队列或栈来优化状态转移。

## 解题思路总结

1. **识别DP问题**：
   - 求最优解（最大值、最小值、最长、最短等）
   - 求方案数
   - 求可行性

2. **分析问题结构**：
   - 是否有最优子结构
   - 是否有重叠子问题
   - 状态如何定义

3. **设计状态转移**：
   - 明确状态的含义
   - 找出状态间的关系
   - 确定边界条件

4. **编码实现**：
   - 选择合适的数据结构
   - 注意计算顺序
   - 考虑空间优化
