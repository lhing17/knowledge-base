## 大事记
- 玄武门之变 唐高祖李渊 -> 唐太宗李世民
- 李世民在位开创了“贞观之治”
- 太子李承乾谋反 李承乾、李泰out 唐太宗李世民 -> 唐高宗李治
- 二圣临朝 李治、武则天共同执政
- 武后鸩杀李弘、废黜并逼死李贤
- 李治驾崩 唐高宗李治 -> 唐中宗李显
- 废黜中宗 唐中宗李显 -> 唐睿宗李旦
- 武曌以周代唐 唐睿宗李旦 -> 武则天
- 神龙政变 武则天 -> 唐中宗李显
- 太子李重俊政变，诛杀武三思，但政变失败被诛
- 韦后、安乐公主鸩杀李显 唐中宗李显 -> 唐恭宗李重茂
- 李隆基发动唐隆政变 唐恭宗李重茂 -> 唐睿宗李旦
- 李旦禅让皇位，成为太上皇 唐睿宗李旦 -> 唐玄宗李隆基
- 开元盛世 李隆基是在位时间最久的唐朝帝王，在位45年，前期开创了“开元盛世”。但中后期由明转昏，宠信宦官，重用权相和外戚，宠幸杨贵妃，酿成了“安史之乱”，亲手将大唐帝国由盛世推向深渊。
- 安史之乱 年迈昏聩的李隆基诛杀名将，自毁长城，导致长安失陷，李隆基出逃巴蜀。太子李亨自行即位，尊李隆基为太上皇。唐玄宗李隆基 -> 唐肃宗李亨
- 藩镇割据 肃宗李亨部分平定了安史之乱，但放弃了李泌提出的彻底收复藩镇的计划，导致在中晚唐的100多年间，藩镇割据的局面持续存在。
- 逼迁上皇 肃宗晚年，宦官李辅国权倾朝野，逼迁上皇李隆基，肃宗虽默许了这一行为，但是始终心怀愧疚，李隆基病死后十几天，肃宗便跟着驾崩了。唐肃宗李亨 -> 唐代宗李豫
- 宦官干政 代宗即位后，除掉了李辅国，但又重用宦官程元振。后赶走程元振，鱼朝恩又接替成为了最有权势的宦官。李辅国、程元振、鱼朝恩先后成为代宗在位期间权势熏天的宦官，随后的唐朝历史里，宦官干政一直是唐帝国抹不去的阴影。
- 外敌入侵 代宗在位期间，吐蕃趁乱入侵，并占据了长安。代宗李豫成为李隆基后又一个丢掉长安的皇帝，幸亏郭子仪用计赶走了吐蕃人，光复了长安。后郭子仪又单骑劝退了回纥入侵者，并联合回纥击退了吐蕃。
- 田承嗣之乱 田承嗣之乱后，朝廷再也无力武力收复各个藩镇，各藩镇成了实际上的国中国。代宗病死后，德宗继位。 唐代宗李豫 -> 唐德宗李适
- 德宗削藩 德宗初上位，权力未稳，急于削藩，结果在与藩镇的战争中败下阵来。作为战败的结果，德宗中后期执政期间，一直对藩镇采取绥靖政策。
- 泾师之变和奉天之难 泾原镇前来勤王的士卒哗变，占据了长安唐德宗仓皇出逃至奉天（今陕西乾县），并被叛军包围一月馀，史称奉天之难。
- 罪己诏 泾师之变后，德宗颁布了罪己诏（陆贽执笔）。这篇《罪己诏》，其辞痛切沉郁、其情挚诚感人，瓦解了反叛联盟，从而建立了“最广泛的统一战线”。
- 顺宗改革 德宗驾崩后，顺宗即位。唐德宗李适 -> 唐顺宗李诵。顺宗即位后，任用王叔文等进行了大刀阔斧的改革。但由于改革影响了多方的利益，加上顺宗病体羸弱，改革仅维持了几个月就宣布破产。顺宗随即将皇位礼让给儿子李纯。唐顺宗李诵 -> 唐宪宗李纯。

杨国忠 | 唐玄宗天宝年间 | 奸相、屡进谗言，导致“安史之乱”朝廷军的大败
安禄山 | 唐玄宗天宝年间至唐肃宗年间 | 发动“安史之乱”，造成了对唐帝国的浩劫，导致唐朝从盛世走向乱世，深刻改变了中国历史的走向。建立“伪燕政权”。
史思明 | 唐玄宗天宝年间至唐肃宗年间 | 在安禄山死后，成为了叛军的新首领，自立为新的燕国皇帝。从此唐朝开启了藩镇割据的乱世局面。这一局面一直持续到唐朝灭亡。
郭子仪 | 唐肃宗年间 | 平定“安史之乱”的头号功臣。借回纥兵收复了长安和洛阳两京，让大唐的政权得以延续。代宗即位后，吐蕃趁虚攻占长安，郭子仪再度被起用，以少数疑兵吓退吐蕃大军，使得长安得以光复。虽功高盖主，却很少得罪人，最后得以善终，并荫及子孙，可谓“千古一人”。
李光弼 | 唐肃宗年间 | 平定“安史之乱”的二号功臣。史思明的天敌，多次有利地遏止了叛军的进攻，在河阳之战中挫败了史思明南下进攻的图谋，使得“安史之乱”得以平息。
李泌 | 唐肃宗年间 | 平定“安史之乱”的谋划者，以白衣身份为肃宗出谋划策，后归隐山林。在代宗和德宗在位时又几度出相，为中唐的稳定立下汗马之劳。
